# Ricery – Inventory Management System

A web-based inventory management system developed using PHP, MySQL, HTML, and CSS for managing rice retail inventory.

## Technologies
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Getting Started

1. Install and open XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Import the project's SQL database through phpMyAdmin.
5. Open your browser and visit:

   `http://localhost/project-folder/`

## Features
- View inventory records
- Add new records
- Update existing records
- Delete records

## Requirements
- XAMPP
- Web browser
- Project database file
